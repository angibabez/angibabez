# hi, i'm andrea 👋

**AI + design builder, creative coder & voice behind Apps + Frappes ☕️**

I build and demo AI + design projects — with lukewarm takes on tech and smarthome along the way. A lot of my work is about figuring out how new technology should actually feel to use, especially when the technology itself is weird, complex, or still being invented.

You'll usually find me prototyping AI agents, vibe coding tiny tools, experimenting with generative interfaces, automating my smarthome setup, or demoing whatever rabbit hole I'm currently going down.
